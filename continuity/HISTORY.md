## 5. Failed attempts and lessons (pattern record)

| Pattern | Instances | Lesson |
|---|---|---|
| Work done before authorization | 3-2c (#9270); Wave 1–2 implementation without task dispatch (#9295) | Implementation without a directive yields only prospective acceptance and permanent provenance UNKNOWNs |
| Counting/arithmetic slips in evidence | #9278 (21→20), #9285 (6→7), #9261 sort-order digest mismatch | Recompute from ground truth; use ordinal byte sorting for digests |
| Truncated Room bodies | #9261 (quote splitting), #9357, Telegram ~4,000 characters | Verify posted bodies; avoid raw quotes through Windows arguments |
| Evidence against a dead dependency | #9352/#9353 (210 invalid captures) | Lesson #001: own the dependencies, check the target loads, verify what was tested |
| Overstated claims in proposals | #9322 (3-1/3-2b "unaccepted"; P3A-2 "permanently rejected by Founder"; wrong producer file) | Verifier caught it at #9323. Attribute to the exact source |
| Paid-seat exhaustion | #9206/#9207 | Conserve seats; unknown quota is not permission |
