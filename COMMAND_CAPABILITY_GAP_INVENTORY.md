## External companion compatibility evidence

The repository does not pin the companion directories as Git submodules or dependencies. `STARQ_AGENT_COMMS_ROOT`, `STARQ_LIFECYCLE_ROOT`, and `STARQ_HERDR_FLOOR_ROOT` resolve independently configurable roots; invalid explicit roots remain unavailable rather than silently falling back. Source imports retain ownership boundaries. Record each companion repository URL, commit SHA, dirty state, runtime/tool versions, and relevant data snapshot hash in the operator's environment manifest before commissioning. This checkout does not provide those version records, so no companion compatibility claim is made from this file. The expected APIs and revision capture procedure are documented in [COMPANION_COMPATIBILITY.md](COMPANION_COMPATIBILITY.md).

Lifecycle status and gates now treat missing companions as unresolved evidence. They do not synthesize successful containment. The filtered lifecycle runner prints each companion-dependent test file it skipped; skips are not passes. Portable CI runs only clone-local typecheck/build and isolated entrypoint/resolver tests.
