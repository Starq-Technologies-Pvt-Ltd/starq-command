# Contributing

This is an internal product under active development. Before contributing:

1. Use a branch and keep changes focused.
2. Preserve source provenance. Do not include live operational data, credentials, personal staff information, generated output, or private evidence bundles.
3. Run relevant tests, typecheck, and build when authorized; report the exact command and result.
4. Describe known limits and distinguish local, simulated, and independently verified behavior.
5. Request review from someone who did not implement the change before treating it as accepted.

Some runtime behavior depends on private Starq workspace sources. Do not use live sources for local development without explicit authorization.
